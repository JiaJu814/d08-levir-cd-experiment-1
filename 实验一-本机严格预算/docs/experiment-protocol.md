# 严格标注预算实验协议第三版

此协议于2026年11月1日完成严格预算核对。使用versions/strict_budget_v3/main.py及configs/base.json，结果保存到runs_strict_v3，原图清单为data/manifests_strict。

此前第二版向上取整，使标称10%用了45/445对（10.1124%），5%用了23/445对（5.1685%）。为满足“仅10%标注”的上限，本版改为向下取整：10%用44/445对（9.8876%），5%用22/445对（4.9438%），20%用89/445对（20%）。旧结果全部保留为探索记录；本版从随机初始化重新训练，不继承曾使用45对标注的权重。算法超参数保持第二版方案，不依据测试成绩修改。

## 修改依据

第一版10%标注、种子17的有标签训练子集变化像素占5.1027%。未平衡BCE加逐图Dice在前20轮的验证F1持续接近零。固定真实训练图块可以被网络学会，且已检查时相与掩膜对应，因此进一步测试类别平衡监督。独立的12轮验证试验最佳F1约0.347，支持用新协议继续训练，但它不是半监督效果，也不是测试集结果。

探索试验同时改变了损失及学习率总周期，因此不据此孤立归因某一损失项的收益。第三版A/B/C/D全部统一使用下述新监督损失。

## 统一监督损失与预算

BCE的正类权重从每次运行自身有标签训练掩膜计算：min(20,非变化像素数/变化像素数)，不使用无标签隐藏标注。Dice在整个批次上汇总，避免空变化图块逐图平均时占据过大作用。A/B/C/D使用相同权重规则、BCE加Dice、同样的强颜色增强、相同采样与优化步数。

各运行均100epoch，每epoch100批、batch=4、crop=256；Adam学习率0.001、weight_decay=0.0001、余弦衰减。验证在第1轮、之后每5轮和最后一轮执行；所有组相同。验证集最高变化类F1选学生权重。推理4个tile一批，不改变非重叠tile几何和完整图指标定义。已检查批量推理与逐tile推理概率一致到浮点容差。

缓存最多64对已解码的有标签原始影像，仅减少PNG重复解码；随机裁剪和增强不变。软件检查确认缓存开启与关闭时，相同随机流输出逐像素一致。无标签数据不缓存，限制内存占用。队列最多并行两次训练，每次PyTorch CPU线程3，适用于本机16GB内存。

## 伪标签与边界

B/D预热10epoch，随后20epoch将无监督权重线性增加到1；教师EMA衰减0.99，置信阈值>=0.95或<=0.05。高置信正类与负类的伪标签BCE分别归一化，各权重0.5；缺少某类时该项为0，避免海量背景压制变化类。此类平衡伪标签损失属于本课题的伪标签策略，不能称为原始Mean Teacher配方的完全复现。

C/D采用半径1的形态学边界带，BCE边界额外权重2；D的无标签边界仅在邻域均高置信时约束。没有增加辅助分支。比较B-A、C-A、D-B及D-C分析独立和组合收益。

有标签、无标签的采样器、DataLoader和增强使用独立随机流。CPU软件检查验证A与B纯监督预热期参数完全一致；不声称不同设备的浮点结果严格逐位一致。断点保留所有随机流、教师、优化器及历史，采用临时文件原子替换，恢复后日志与最近完整epoch对齐。

## 数据与评价

保留原始445/64/128划分。按原图对、向下取整、嵌套抽样，3种子为17/42/2026；5%/10%/20%为22/44/89对。无标签清单不含标签路径，原始标签不改写，读取时0为不变、非零为变化。709个非0/255像素的源文件计数记录于审计。

固定概率阈值0.5。区域指标从全测试集混淆矩阵汇总；边界F1在完整图上计算，容忍距离2像素（曼哈顿距离）。原始F1为0到1，乘100后的差才是百分点。

主要目标为10%标注下B-A的三个配对种子测试F1差值均值>=3个百分点。报告每个差值、均值、样本标准差和95%配对t区间；均值达标不等于统计显著，3种子对区间估计的支持有限。

优先完成10%的A/B三个种子主对照，再完成C/D三个种子与100%参考，随后扫描5%与20%。整个矩阵39次，代码和配置冻结，所有模型按同一验证规则选权重。10%的A/B六个运行完成后，队列生成主要目标的测试判定；其余预算结果随后补全。任何失败都停止新任务并保存断点，不能伪称任务完成。

## 外观与边界分析

对10%全部组和种子的冻结模型，分别将第二时相亮度乘0.8、1.2，与原始测试配对比较F1与虚检率。原标签保持不变。该受控扰动不能当作真实季节变化的因果证据。全部测试保留逐图指标与前8幅可视化；最差/最优案例及真实阴影解释仍需人工检查，不夸大边界和泛化效果。

有限标注下的策略优先按三种子验证F1均值选择，再报告该策略对应测试结果和训练开销，不按测试成绩挑选后声称普遍最优。若未提升3个百分点，最终报告必须明确“未达到”，并给出实际数值。


## 预算与结果审查

训练入口检查audit.rounding必须为floor，实际有标签对数必须精确等于floor(训练集对数×百分比/100)，不符合则拒绝训练。配置保存实际标注比例；结果报告同时核对清单、预算、训练版本和代码/数据指纹，配对F1达标但预算不符时仍不能判定达标。软件检查使用25对构造数据验证5%只有1对、10%只有2对，构造数据不进入研究结果。
